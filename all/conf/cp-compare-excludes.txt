# Exclusion list for the cp-compare report
# (CompareTask 'excludesfile' attribute, classpath side, all/build.xml).
#
# Upstream-only files matching these patterns are hidden from the report
# instead of showing up as "Exists only in classpath" rows. Use this for
# GNU Classpath APIs that were INTENTIONALLY removed from the classlib
# and must never be re-synced.
#
# Patterns match the tree-relative file names of the upstream classpath
# checkout ('/' separators). Two granularities are supported:
#
#   package granularity : gnu/java/nio/charset/**
#   per-class granularity : java/nio/ByteBufferImpl.java
#
# Rules the task enforces:
# - exclusions apply ONLY to upstream-only rows. Files present in the vm
#   tree are always compared and reported normally, so a resurrected file
#   still shows up (as "Exists only in vm").
# - keep patterns tight: siblings that are KEPT must keep comparing,
#   e.g. java/nio/channels/** is NOT covered by java/nio/* below.
#
# --- java.lang.Thread: replaced by the OpenJDK Thread
#     (core/src/openjdk/java/java/lang/Thread.java, JNode-ported:
#      String name, appended vmThread/isolatedStatics fields). The GNU
#      Classpath Thread was deleted, so every future sync would otherwise
#      report it as a missing file. Note that sun/.* and the classlib's own
#      Thread.java variants are unaffected. ---
java/lang/Thread.java

# --- java.nio buffers: replaced by the OpenJDK SPP-generated buffers
#     (core/src/openjdk/tools/nio templates, built into core/build/gen-src).
#     The GNU buffer implementations were deleted wholesale; AbstractBuffer,

#     VMDirectByteBuffer and the MappedByteBufferImpl are gone. ---
